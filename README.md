# Системный аналитик с нуля

Статический сайт-курс: 16 недель, 15 модулей, 117 готовых уроков (текст + проверочные задания), поиск, тёмная тема и прогресс (хранится в браузере).

## Формат урока

Каждый топик из `Курс/02_Топики.md` — отдельный урок: теория с примерами, затем блок «Проверка знаний» (3–4 задания). Типы заданий: один ответ, несколько ответов, короткий ответ (проверка по регулярным выражениям), практика (самопроверка по критериям с эталоном). Урок считается пройденным, когда выполнены все задания. Варианты ответов перемешиваются при показе. У модулей M13–M14 уроков нет — это капстоун и карьера, там ручная отметка.

## Запуск локально

1. Скачайте репозиторий (**Code → Download ZIP**) или `git clone`.
2. Вариант А — просто откройте `index.html` в браузере.
3. Вариант Б (надёжнее, нужен Python 3): запустите `start.bat` (Windows) или `./start.sh` (macOS/Linux) и откройте <http://localhost:8000>.

Никаких зависимостей и сборки для просмотра не требуется.

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `assets/` | сайт (HTML, CSS, JS без библиотек) |
| `Курс/*.md` | программа курса: модули, топики, план |
| `assets/lessons/m0.js … m12.js` | тексты уроков и задания (формат описан ниже) |
| `tools/validate-lessons.js` | проверка файлов уроков: `node tools/validate-lessons.js assets/lessons/m0.js` |
| `build.py` | собирает `assets/content.js` из `Курс/*.md` (`py build.py`) |

После правки Markdown запустите `py build.py` и закоммитьте обновлённый `assets/content.js`.

## Как править урок

Урок — запись в `assets/lessons/mN.js` по id топика:

~~~js
"0.1": {
  title: "Название",
  body: `markdown урока`,          // без обратных кавычек и ${ внутри; код — в блоках ~~~
  q: [
    { t: "single", q: "Вопрос", o: ["A", "B", "C"], a: 1, e: "Почему B" },
    { t: "multi",  q: "...", o: ["A", "B", "C", "D"], a: [0, 2], e: "..." },
    { t: "short",  q: "...", a: ["регулярка", "другая"], sample: "эталон" },
    { t: "task",   q: "...", rubric: ["критерий 1", "критерий 2", "критерий 3"], sample: "markdown-эталон" }
  ]
}
~~~

После правки запустите валидатор. Список топиков берётся из `Курс/02_Топики.md` (после его правки — `py build.py`).
