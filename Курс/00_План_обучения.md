# Курс «Системный аналитик с нуля» — план обучения

**Для кого:** человек, который ни разу не работал в IT.
**Формат:** 16 недель, ~10–12 часов в неделю (≈ 180 часов): теория 40% / практика 60%.
**Результат:** портфолио из 3 артефактов + умение пройти собеседование на позицию Junior системного аналитика.
**Актуальность:** см. [01_Актуальное_для_2027.md](01_Актуальное_для_2027.md). Подробные топики — [02_Топики.md](02_Топики.md).

## Принципы курса

1. **От простого к сложному.** Каждый термин вводится на бытовом примере (заказ в кафе, библиотека, доставка), потом переносится на IT.
2. **Каждый модуль = понятие → пример → ошибка новичка → практика → мини-тест.**
3. **ИИ используем как ассистента с первой недели** (черновики, объяснение терминов, проверка), но итоговый результат проверяет и подписывает человек.
4. **Единый сквозной проект** («Сервис заказа еды» или «Электронная библиотека») — на нём отрабатываются все модули.

## Итоговые артефакты (портфолио)

1. Пакет требований (BRD-lite + FR/nFR + Use Cases + матрица трассировки).
2. Модели: BPMN, Activity, Sequence, ER, State Machine, схема архитектуры.
3. Интеграционный пакет: OpenAPI-спека + AsyncAPI/описание события + примеры в Postman.
4. (Бонус) Требования к AI-фиче: сценарии, tools/API, риски, метрики качества.

## Оценивание

- Мини-тесты после каждого модуля (10 вопросов).
- 1 практическое задание на модуль (по чек-листу).
- Финальный капстоун с защитой (критерии — в M13).
