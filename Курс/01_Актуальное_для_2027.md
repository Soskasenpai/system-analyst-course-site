# Что нужно знать системному аналитику в 2027 году

Дата сбора: ноябрь 2026. Источники — выборка вакансий hh.ru / Habr Career 2026 и англоязычные обзоры. Выборка небольшая, поэтому выводы ориентировочные. Пункты, помеченные «⚠ проверить», опираются на один вторичный источник.

## 1. Что стабильно требуют в вакансиях (ядро профессии)

| Область | Что именно просят |
|---|---|
| Моделирование | BPMN, UML (Use Case, Activity, Sequence, Class), ER-диаграммы |
| API | Проектирование REST API, OpenAPI/Swagger, API-first, тестирование в Postman |
| Интеграции | Синхронные (REST, SOAP) и асинхронные (Kafka, RabbitMQ), форматы JSON / XML / YAML |
| Данные | SQL (JOIN, GROUP BY, HAVING, EXISTS), проектирование БД, транзакции |
| Процессы | Agile / Scrum, иногда Waterfall; Jira + Confluence |
| Требования | FR / nFR, user stories, Use Cases, матрица трассировки, приёмочные критерии |

Это совпадает с материалами из папки (главы 01–06). **Фундамент остаётся тем же, его не заменяет ничто.**

## 2. Что новое и усиливается к 2027

1. **AI / LLM в продуктах.** В вакансиях появилось «проектировать взаимодействие LLM-агентов и систем: от запроса пользователя до вызова внешнего API», а также RAG и агентные системы. Аналитик описывает: что агент может делать, какие инструменты (API) ему доступны, что происходит при ошибке, где нужен человек.
2. **MCP (Model Context Protocol).** Открытый стандарт подключения ИИ к инструментам и данным. В декабре 2025 передан в Agentic AI Foundation (Linux Foundation). Последняя ревизия спецификации датирована 28.07.2026 ⚠ проверить на modelcontextprotocol.io. Для аналитика это «ещё один тип API-контракта»: описать tools, права, ограничения.
3. **AI как рабочий инструмент аналитика.** Черновики требований, user stories, BPMN-текстовые описания, тест-кейсы, SQL, OpenAPI — всё это ускоряется ИИ. Ценность смещается в **проверку, уточнение и ответственность за результат**. Рынок воспринимает аналитика как «хранителя системы» (system steward), а не «писаря документов».
4. **Асинхронные API и события.** OpenAPI 3.2 (сентябрь 2025) добавил поддержку streaming, иерархических тегов. AsyncAPI 3.x описывает Kafka / AMQP / MQTT / WebSocket. Событийные архитектуры требуют от аналитика умения проектировать топики, ключи, идемпотентность, повторы и DLQ.
5. **Качество данных и governance.** Данные, права доступа, персональные данные, аудит, этичность ИИ — теперь часть требований, а не «забота безопасников». BABOK v4 (по обзорам) отдельно упоминает этичный ИИ, кибербезопасность, устойчивость ⚠ проверить на iiba.org.
6. **Automation / low-code / workflow.** Интеграция API, автоматизация процессов, оркестрация — растущие навыки у аналитиков.
7. **Рынок.** Зарплаты в IT растут медленнее инфляции (Habr Career, 2026); вилки для системных аналитиков примерно 60 тыс. ₽ (джуниор-входы) — 200–300 тыс. ₽ (сильные middle/senior). Конкуренция на вход выше: нужны портфолио и практика, а не только сертификат.

## 3. Что НЕ нужно (в 2027 году)

- Не нужно заучивать нотации наизусть: достаточно владеть 20% BPMN, которые применяются в 90% случаев.
- Не нужно становиться разработчиком: нужно читать код/запросы и понимать контракты.
- Не стоит делать ставку на «чистый ИИ без понимания»: ИИ ошибается в доменных деталях, и именно аналитик это ловит.

## 4. Профиль навыков 2027 (Т-образный)

- **Ширина:** бизнес-процессы, требования, архитектура, данные, интеграции, тестирование, безопасность, AI-основы.
- **Глубина (на выбор):** (а) интеграции и API; (б) данные/SQL/DWH; (в) AI-продукты и агенты; (г) домен (финтех, ритейл, телеком и т. д.).
- **Soft skills:** интервью, переговоры, письменная ясность, фасилитация, работа с неопределённостью.
